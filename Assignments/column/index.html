What still feels confusing about Flexbox?



Even though I've been using Flexbox for a lot of my assignments, I'd say there's still a lot I don't know about it because I've only used it for doing the same few things. I still don't know what are all the things you could do with it, and even for cases where I think it's possible to use Flexbox in a certain way, I wouldn't really know how to do it. For example, I thought it would be better if you didn't need to zoom out in order to view the full page and it shrunk down more, and while I think that's possible with Flexbox, I wouldn't know how to set up the Flexbox without ruining the orientation of the whole page. I also don't know how to get more precise when using Flexbox either, since I've only seen properties that seem to format the boxes in specific ways instead of being at a specific spot, unless maybe I spent a lot of time getting the padding and margins to be just right.
