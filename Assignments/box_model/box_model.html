What happened when you changed an element's display property?

It ended up chaning the way the elements were oriented on the page itself. For example, the inline display property made the text horizontal and they didn't take up the whole screen width after. When I used flex display and column direction on the a tags at the bottom, they ended up being stacked vertically and ended up being the width of the entire screen until I set the width myself.


What did you learn from using the browser Inspector?

I was able to learn that you could use it to relatively easily check the size of different elements on the page. I also learned that the navigation of the inspect element page is pretty different from just the code itself, and there are a lot of other aspects of the web page that aren't present here. In general, the function does still feel pretty useful, and I should probably learn how to navigate it more so I can learn from other websites more easily.


What helped you understand the difference between margin and padding?

Something that helped me understand was how in line paper, the part separated by the red line is the margin, which you shouldn't write on. That means margins are outside of the element, and that leaves padding as being forced to be part of the inside of the element.
